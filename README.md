# VActPyGenExplore
Just a library to explore and test generative or other machine learning models using python, mostly to extend piplines in other projects to do pre or post work in automation

## Setup
Make sure you set `HF_API_KEY` system env variable for Hugginface models and `CIVITAI_API_KEY` system env variable for Civit AI models. or change the `api_key_var` in the `pipeline-*.json` files to your system env variables.
