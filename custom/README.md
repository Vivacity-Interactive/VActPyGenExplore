# Custom ML-Models
here are custom models that are more for pre or post processing or feature extraction and such, includes tools such as gsplat.
## SAM2
Currently contains a minimal interface to navigate frames 
- frame `rarrow|larrow|d|a` forward and backward, 
- play `space`
- propagate `shift+enter`, 
- navigate `object_id` for hint placement `uarrow|darrow|w|s` previous and next. 
- hint placement `lmouse|rmouse` positive and negative hints
- hint remove nearest in radius `lmouse+shift|rmouse+shift` posetive and negative
- change play fps `[` and `]` down and up
- `esc` to end session and write results

this is a quick setup unpolished, system will writes hints away to be able to load again later, this initialization needs some improvement, but generaly working.
